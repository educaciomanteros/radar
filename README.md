# Top Manta · Radar d’oportunitats

[Obre el Site privat unificat](https://top-manta-radar-ajuts-m8q2.stollenart.chatgpt.site)

Festivals i finançament en un únic espai: portada, `/festivals/` i `/economia/`. El codi complet és a `ajuts/`, amb 16 festivals i 32 línies de finançament de partida. El seguiment és local al navegador; les notes dels festivals antics es traslladen amb còpia JSON.

`plugin-update/` conserva l’actualització parcial 0.8.2 del plugin de comunicació. GitHub no activa desplegaments automàtics; el Site es publica a través de Sites.
