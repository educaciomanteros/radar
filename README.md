# Top Manta · Radar d’oportunitats

[Obre el Site privat](https://top-manta-radar-ajuts-m8q2.stollenart.chatgpt.site) · [Matriu de subvencions](https://top-manta-radar-ajuts-m8q2.stollenart.chatgpt.site/matriu/)

Festivals, radar econòmic i matriu de gestió en un únic Site. El codi és a `ajuts/`, amb portada, `/festivals/`, `/economia/` i `/matriu/`.

La matriu gestiona projectes, pressupostos, candidatures, cobraments, despeses, imputacions, calendaris i avisos. No inclou imports ni concessions ficticis. Les dades de gestió es desen al navegador i no formen part d’aquest repositori. Exporta una còpia JSON per conservar-les; els CSV permeten consultar les taules a Excel.

`plugin-update/` conserva l’actualització parcial 0.8.2 del plugin de comunicació. Publicació amb Sites, sense desplegament automàtic des de GitHub.
